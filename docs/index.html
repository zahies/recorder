Sound Recorder

ICS-43434 I2S Microphone Array

Install Firmware

Connect your Heltec WiFi LoRa 32 via USB-C, then click install.

Your browser doesn't support Web Serial.
Use Chrome or Edge on desktop. Web Serial is not allowed in this context.

How to Use

  1. After flashing, connect your phone to WiFi: ESP32-Recorder (password: za12xs43)
  2. Open http://192.168.4.1 in your phone's browser
  3. Tap Record to start recording
  4. Tap Stop to stop
  5. Tap Download WAV to save the file

Requires Chrome or Edge. Works on ESP32-S3 (Heltec WiFi LoRa 32 V3/V4).

Hardware Setup

4x ICS-43434 microphones in a tetrahedral configuration.

  1. GPIO18 (pin 12) → SCK / BCLK of all four mics
  2. GPIO19 (pin 35) → WS / LRCLK of all four mics
  3. GPIO20 (pin 38) ← SD from Mic 1 (L/R=LOW) & Mic 2 (L/R=HIGH)
  4. GPIO22 (pin 15) ← SD from Mic 3 (L/R=LOW) & Mic 4 (L/R=HIGH)

Install Overlay & Software

# Compile and install the device tree overlay
sudo dtc -@ -I dts -O dtb \
  -o /boot/overlays/four-mics.dtbo \
  rpi/four-mics.dts

# Add to /boot/config.txt
echo "dtoverlay=four-mics" | sudo tee -a /boot/firmware/config.txt

# Reboot to activate
sudo reboot

# After reboot, verify the sound card
arecord -l   # should show "four-mics"

# Install Python dependencies
pip install -r rpi/requirements.txt

How to Use

  1. Start the recorder: sudo python3 rpi/recorder.py --port 80
  2. Open http://<rpi-ip> in your browser
  3. Click Record to capture 4-channel audio
  4. Click Stop to finish
  5. Click Download WAV to save the 4-ch file
  6. Use Live Spectrum to view real-time FFT (channel 0)

Raspberry Pi 5 only. Records 4-channel 16 kHz 16-bit WAV to disk.
